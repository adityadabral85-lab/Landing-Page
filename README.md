# Beginner Landing Page Project

A simple GitHub-ready landing page project made with HTML, CSS, and JavaScript.

## Files

- `index.html` - Page structure and content
- `style.css` - Layout, colors, spacing, and responsive design
- `script.js` - Mobile menu interaction

## How to Run

Open `index.html` in your browser.

You can also use the VS Code Live Server extension if you want automatic refresh while editing.

## How to Push to GitHub

```bash
git init
git add .
git commit -m "Add landing page project"
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/YOUR-REPOSITORY.git
git push -u origin main
```

Replace `YOUR-USERNAME` and `YOUR-REPOSITORY` with your GitHub details.
